# Pivot Uzbekistan Telegram Bot

PHP and MySQL application planned for Ahost shared hosting.

## Project status

Repository initialized for development. The bot and admin panel have not been implemented or tested yet.

## Agreed scope

- Mandatory Telegram membership checks for @pivotuzbekistan.
- Uzbek Demo Day application flow: full name, startup name, own Telegram contact, and project document or photo.
- Persistent drafts and duplicate-submission protection.
- Admin application search, review statuses, internal notes, and applicant notifications.
- Excel and PDF application exports with original attachments available separately.
- Overall statistics: users, membership checks, application completion, registration drop-off, review statuses, overdue reviews, trends, and notification delivery.
- PHP webhook endpoint, MySQL database, and short cron tasks suitable for shared hosting.
- Event: Grand Demo Day, November 19, 2026; timezone Asia/Tashkent.

## Configuration

Deployment credentials will be configured privately on the host. Never commit bot tokens, database passwords, applicant records, or uploaded documents.
